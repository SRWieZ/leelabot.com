Urban Terror · PHP · GPL-2.0+

Run your Urban Terror servers from the chat box.

Leelabot sits between the two teams and your RCon. It answers admin commands typed in game, hands out warns and bans on its own, and keeps the stats.

What it does

It never talks to the game directly. It follows the log files each server writes, hands what it finds to the plugins you loaded, and answers on whichever channel makes sense.

Reads

  • games.log server 1
  • games.log server 2
  • games.log server 3

One games.log per server. Leelabot follows them all at once and turns every line into an event.

Dispatches

  • adminbase
  • basicrights
  • stats
  • bans
  • warns
  • logs

The core parses the server and fires events. Every feature is a plugin listening for the ones it cares about.

Answers

  • RCon back into the game
  • IRC your channel
  • TeamSpeak who's in voice

Replies go back to the players over RCon, and out to the channels your admins are already sitting in.

Commands, typed in game

Rights are per command and per admin level, so trusted regulars can call a vote without ever getting near your RCon password. Hover one to see what it does.

  • Kicks a player from the server.
  • Bans a player. The ban list is kept on disk and survives a restart.
  • Mutes a player in the server.
  • Slaps a player from the server.
  • Warns a player. Enough warnings and they get kicked automatically.
  • Clears a player's accumulated warnings.
  • Change the current map. Reloads the server.
  • Go to the next map.
  • Change the map that comes next.
  • Cancel a vote in progress.
  • Pause the game.
  • Shuffle the teams, with a restart.
  • Swap the two teams.
  • Force a player into a team.
  • Print a large message across everyone's screen.
  • Send a message to everyone.
  • Kills, deaths and ratio for the round.
  • Announce the end-of-round awards.
  • Promote a player to an admin level.
  • Give a player a specific level.
  • List the players on the server.
  • Send an RCon command straight to the server.
  • Reload the game.
  • Stop the bot.

Plugins in the box

Load only what a server needs. Each one is a single PHP file you can read, fork, or use as the template for your own.

adminbase
Most of the admin commands: kicks, maps, votes, server control.
assault
Helpers for the Assault gametype.
bans
Ban players and keep the ban list on disk.
basicrights
Simple rights management, built for ease of configuration.
clientbase
Player-facing commands: !teams, !time, !nextmap, !help.
dummy
A skeleton to copy when you start your own plugin.
irc
A full IRC bot bridging server chat to a channel.
logs
Logs all activity on each server separately.
messages
Recurring announcements posted in chat on a timer.
stats
Game statistics for every player, plus end-of-round awards.
teamspeak
Reports who is currently on the TeamSpeak server.
warns
Auto-warns teamkilling and insults, kicks repeat offenders.

Get it running

Clone it, point the config at your server's RCon, and start the bot. It runs as a long-lived CLI process — screen, tmux or a systemd unit all work.

PHP
5.3.0 or newer
PHP-CLI
the bot runs from the terminal
intl
optional, for translations

$ git clone https://github.com/ylorant/Leelabot.git

$ cd Leelabot

# edit the config, then:

$ php bot.php
