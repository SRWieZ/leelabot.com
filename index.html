What it does

One process, every server

Leelabot dispatches to as many Urban Terror instances as you throw at it, each with its own configuration and its own set of plugins.

Everything is a plugin

The core parses the server and fires events. Features live in plugins — drop a PHP file in plugins/, hook the events you care about, reload.

RCon from the chat box

Change maps, force teams, veto votes, pause the round or slap someone, all typed straight into in-game chat instead of a console.

Moderation on autopilot

Warns fire automatically on teamkilling and insults, and kick the players who keep at it. Bans persist to disk and survive a restart.

Stats and awards

Per-player statistics tracked across the round, with end-of-game awards announced in chat. Players pull their own with !stats.

Bridged to IRC and TeamSpeak

A full IRC bot relays the server chat to your channel, and the TeamSpeak plugin reports who is sitting in voice.

Commands, typed in game

Rights are per command and per admin level, so trusted regulars can call a vote without ever getting near your RCon password.

Plugins in the box

Load only what a server needs. Each one is a single PHP file you can read, fork, or use as the template for your own.

adminbase
Most of the admin commands: kicks, maps, votes, server control.
assault
Helpers for the Assault gametype.
bans
Ban players and keep the ban list on disk.
basicrights
Simple rights management, built for ease of configuration.
clientbase
Player-facing commands: !teams, !time, !nextmap, !help.
dummy
A skeleton to copy when you start your own plugin.
irc
A full IRC bot bridging server chat to a channel.
logs
Logs all activity on each server separately.
messages
Recurring announcements posted in chat on a timer.
stats
Game statistics for every player, plus end-of-round awards.
teamspeak
Reports who is currently on the TeamSpeak server.
warns
Auto-warns teamkilling and insults, kicks repeat offenders.

Get it running

Clone it, point the config at your server's RCon, and start the bot. It runs as a long-lived CLI process — screen, tmux or a systemd unit all work.

PHP
5.3.0 or newer
PHP-CLI
the bot runs from the terminal
intl
optional, for translations

$ git clone https://github.com/ylorant/Leelabot.git

$ cd Leelabot

# edit the config, then:

$ php bot.php
